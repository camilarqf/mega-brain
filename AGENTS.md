# Mega Brain — instruções para Codex (GPT)

Este repositório contém conhecimento em Markdown para Obsidian e quatro Agent Skills compartilhadas com Claude Code. Consulte `BRAIN-RULES.md` para convenções.

- Consulte `Catalogo-de-Sistemas.md` para relacionar repositórios a sistemas de negócio.
- Use a Skill adequada quando solicitado: `documentar-sistema`, `atualizar-documentacao`, `consultar-conhecimento`, `sincronizar-brain`.
- Use o mesmo vocabulário de `type` definido em `BRAIN-RULES.md` (tabela "Tipos de nota") e o schema de frontmatter ali descrito; escolha o tipo pelo conteúdo e atualize notas existentes em vez de duplicá-las.
- Registre referências verificáveis ao código e a commits; diferencie confirmação, inferência e lacunas.
- Não modifique código-fonte ao documentar, não mova notas nem publique conteúdo sem aprovação.
- Não copie código, documentação ou dados institucionais para armazenamento pessoal não autorizado.
- Não presuma que o cofre Obsidian está montado: confira o caminho e as permissões na sessão.
